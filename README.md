## 📋 Sobre o Projeto

Interface de login com visual moderno, contendo:

- Fundo com gradiente animado e efeito de ondas
- Campos de usuário e senha
- Botão de entrar com animação de hover
- Links para recuperação de senha e cadastro

O repositório também inclui uma segunda versão mais simples na pasta `login2/`.

## 🚀 Como rodar localmente

2. Abra o arquivo `index.html` no navegador

Ou acesse a versão online pelo link da demonstração.
